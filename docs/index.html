The J Programming Language

J is a small, dynamically-typed language that runs instantly through an interpreter and compiles to parallel native code when you need speed.

You write ordinary code — functions, sequences, maps, classes — and run it with j file.j. Most programs execute immediately, with no build step. When a program is compute-heavy, j build compiles it to a native binary and parallelizes the hot loops automatically. Installing J installs everything it needs; there is no separate toolchain to manage.

Hello, world

print("Hello, world")

Run it:

$ j hello.j
Hello, world

A taste

# Find the longest word.
words = ["apple", "banana", "fig", "grapefruit"]

func longest(ws) = {
    best := ""
    for w in ws {
        if len(w) > len(best) { best = w }
    }
    give best
}

print(fmt("longest: {} ({} chars)", longest(words), len(longest(words))))

This shows the essentials: a constant binding (=), a mutable one (:=), a function with a block body, a for loop, and string formatting with fmt.

Why J

Instant

Programs run through an interpreter by default — no compile wait. Good for scripts, learning, and fast iteration.

Fast when it matters

j build compiles to native code and parallelizes idiomatic loops (reductions, element-wise maps, matrix×vector) across cores — no annotations.

Self-contained

You install J, not a toolchain. No system Rust, no package manager, no network needed to compile a program.

Familiar

A small, readable syntax: constants and mutables, functions and lambdas, classes, sequences and maps, and typed error handling.
