Standard Library

Built-in functions are always available by name. Grouped utilities live in modules, accessed with dot syntax (math.cbrt(x), time.now()).

Built-in functions

Input / output

FunctionDescription
print(v)Print a value followed by a newline.
fmt(template, ...)Format text; each {} is replaced by the next argument.
input()Read a line from standard input.

Conversion and inspection

num(text)Parse text into a number.
str(v)Convert a value to its text form.
len(v)Length of a sequence, map, or text.
type_of(v)The type name of a value.

Sequences

make_seq(n, init)A sequence of length n filled with init.
push(s, x)Append x to a mutable sequence, in place.
sum(s) · min(s) · max(s)Reduce a sequence to a single value.
sort(s) · sort_by(s, cmp)Sorted copy (optionally by a comparator function).
reverse(s) · unique(s)Reversed / de-duplicated copy.
slice(s, i, j)Sub-sequence from index i to j.
take(s, n) · skip(s, n)First n / all but the first n.
contains(s, x) · count(s)Membership test / element count.
map(s, f) · filter(s, f) · reduce(s, init, f)Higher-order transforms.
zip(a, b) · enumerate(s) · flatten(s)Combine / index / un-nest.
join(s, sep) · collect(flow)Join into text / materialize a flow.

Math

abs · sqrt · pow(b, e)Absolute value, square root, power.
floor · ceil · roundRounding.
clamp(x, lo, hi)Constrain x to a range.

Text

upper(t) · lower(t) · trim(t)Case conversion, whitespace trimming.
split(t, sep)Split text into a sequence.

Modules

Modules group related functions and are called with dot syntax. The fs, proc, and http modules touch the outside world and are denied by default — enable them per run with capability flags (see the CLI Reference).

math

Floating-point math: sin, cos, tan, exp, ln, log, log2, log10, cbrt, trunc, sign, clamp, and more.

print(math.sqrt(2.0))
print(math.log2(1024.0))   # 10

stats

Summary statistics over a sequence: count, sum, avg, median, mode, range.

str

Text operations beyond the built-ins: replace, replace_n, find, rfind, starts_with, ends_with, and byte conversions.

json

Read and write JSON: parse(text), stringify(value), stringify_pretty(value).

data = json.parse("{\"n\": 42}")
print(data["n"])                   # 42
print(json.stringify([1, 2, 3]))   # [1,2,3]

regex

Regular-expression matching; match results expose start, end, and text.

time / date

time.now() and time.elapsed_ms(t) for timing. date exposes epoch_secs, epoch_millis, year, month, day, hour.

t = time.now()
# ... work ...
print(fmt("took {} ms", time.elapsed_ms(t)))

rand

Random numbers: seed(n), next_int(), next_float(), next_range(lo, hi). Seed for reproducible output.

hash / hex / base64

Digests and encodings: hash.xxhash, hash.md5, hash.sha256; hex.encode / hex.decode; base64.encode / decode (and the URL-safe variants).

bits

Bitwise functions as an alternative to the operators: band, bor, bxor, bnot, shl, shr.

sys

System information: os, arch, hostname, username, cpu_count.

fs — needs --allow-fs

Filesystem access: read_file, write_file, size, is_dir, is_file, modified_epoch.

proc — needs --allow-proc

Run processes and read the environment: process results expose stdout, stderr, status; plus argv, env, set_env.

http — needs --allow-net

HTTP requests: get, post, post_json; responses expose status, body, headers.

async

Concurrency helpers: parallel(tasks) runs functions concurrently, sleep_ms(n), and async I/O like http_get / read_file.

This page summarizes the most common entry points. The set of functions grows with the language; the authoritative list is the runtime source.
