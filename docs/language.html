Language Guide

The complete J language: values, bindings, control flow, functions, data structures, classes, and error handling.

Comments

Comments start with # and run to the end of the line.

# This is a comment.
x = 1   # so is this

Values and types

J has a small set of built-in value types:

TypeExampleNotes
int42, -764-bit signed integer
float3.14, 1.064-bit floating point
text"hello"a string of characters
booltrue, false
nullnullthe absence of a value
seq[1, 2, 3]an ordered sequence
map{"a": 1}a text-keyed map

Numbers mix as you'd expect: an operation involving a float produces a float. Integer division yields an integer when it divides evenly and a float otherwise (6 / 2 is 3; 7 / 2 is 3.5). Use num(...) to convert text to a number.

Bindings

A name is bound with = (constant) or := (mutable). A constant cannot be reassigned; a mutable can.

pi = 3.14159      # constant — reassigning it is an error
count := 0        # mutable
count = count + 1 # ok
count += 1        # ok (compound assignment)
count++           # ok (increment)

Compound assignment operators are +=, -=, *=, /=, and %=; ++ and -- increment and decrement. A function-local binding may shadow a same-named binding from an outer scope.

Operators

and and or short-circuit. Note that ^ is bitwise XOR — use ** for exponentiation.

print(2 ** 10)        # 1024
print(13 % 5)         # 3
print(true and false) # false
print(6 & 3)          # 2  (bitwise)

Ranges

A range a..b is inclusive of both ends. 1..5 is 1, 2, 3, 4, 5. Ranges are most often used to drive a loop:

for i in 0..4 { print(i) }   # prints 0 1 2 3 4

Control flow

Conditionals

if score >= 90 {
    print("A")
} else if score >= 80 {
    print("B")
} else {
    print("C")
}

Loops

Loop over a range or over the elements of a sequence:

for i in 1..n { ... }       # inclusive range
for item in items { ... }   # each element

A loop may include a filter — for x in xs if pred runs the body only for elements where the predicate function returns true:

func is_even(n) = n % 2 == 0
for x in nums if is_even { print(x) }

repeat loops while a condition holds:

i := 0
repeat i < 3 {
    print(i)
    i += 1
}

Inside a loop, stop breaks out and skip continues with the next iteration. Both accept an optional condition (stop if done).

Assertions

assert x > 0
assert x > 0, "x must be positive"

Functions

A function is defined with func. The body is either a single expression or a block. In a block, give returns a value (and exits the function early):

# expression body
func square(x) = x * x

# block body
func classify(n) = {
    if n < 0 { give "negative" }
    if n == 0 { give "zero" }
    give "positive"
}

print(square(9))        # 81
print(classify(-3))     # negative

Functions may call themselves recursively:

func fib(n) = {
    if n < 2 { give n }
    give fib(n - 1) + fib(n - 2)
}

Lambdas and higher-order functions

An anonymous function is written func(params) = expr. Functions are values: you can pass them to the higher-order built-ins map, filter, reduce, and sort_by.

nums = [1, 2, 3, 4, 5]

squares = map(nums, func(x) = x * x)            # [1, 4, 9, 16, 25]
evens   = filter(nums, func(x) = x % 2 == 0)    # [2, 4]
total   = reduce(nums, 0, func(a, b) = a + b)   # 15
desc    = sort_by(nums, func(a, b) = b - a)     # [5, 4, 3, 2, 1]

The pipe operator >> applies a function across a sequence — a concise alternative to map:

func sq(x) = x * x
result = nums >> sq            # [1, 4, 9, 16, 25]

Sequences

A sequence is an ordered, indexable collection written with square brackets. Indexing is zero-based; assigning to an index updates the element in place.

xs = [10, 20, 30]
print(xs[0])          # 10
print(len(xs))        # 3

ys := make_seq(3, 0)  # [0, 0, 0]
ys[1] = 99            # [0, 99, 0]
push(ys, 7)           # append -> [0, 99, 0, 7]

Common operations: len, sum, min, max, sort, reverse, slice, contains, unique, zip, enumerate, take, skip, flatten, and join. See the Standard Library for the full list.

Maps

A map associates text keys with values. Read and write entries with index syntax m[key] or member syntax m.key.

scores = {"alice": 90, "bob": 85}
print(scores["alice"])    # 90
print(scores.bob)         # 85

prices := {"pen": 2}
prices["book"] = 12       # add / update

Text

Text values are strings. Build formatted text with fmt, where {} is a placeholder filled by the following arguments. The str module provides operations like split, replace, find, starts_with, and ends_with.

name = "Ada"
print(fmt("Hello, {}! You have {} messages.", name, 3))
print(len("hello"))               # 5
print(upper("hello"))             # HELLO
parts = split("a,b,c", ",")       # ["a", "b", "c"]

Classes

A class is defined by assigning class { ... } to a name. Fields are declared with a type; methods use func-like syntax with a return type and refer to fields directly (or through self). Construct an instance by calling the class — positionally or with named fields.

Point = class {
    x: float
    y: float
    dist() -> float = sqrt(x * x + y * y)
    scale(k: float) -> float = (x * x + y * y) * k
}

p = Point(x: 3.0, y: 4.0)   # named fields
q = Point(1.0, 2.0)         # positional
print(p.dist())             # 5
print(p.x)                  # 3

A class may extend another with extends, inheriting its fields and methods.

Error handling

Runtime errors belong to typed error classes (for example ZeroDivisionError, ConversionError, IndexError, ArithmeticError). Handle them with a try block followed by one or more else handlers; a bare else catches anything not matched above it.

try {
    x = 10 / 0
} else ZeroDivisionError {
    print("caught: division by zero")
} else {
    print("some other error")
}

Handlers match by class, and a parent class catches its subclasses — else ArithmeticError catches ZeroDivisionError and OverflowError, and else Error catches essentially everything.

Modules and imports

Split a program across files with import. The imported file's source is inlined at that point; imports are resolved transitively and cycles are broken (importing the same file twice is a no-op).

import "util.j"        # next to this file, or in ./lib/, or on J_PATH
import "/abs/path.j"   # absolute path

A non-absolute import is searched for, in order: next to the importing file, then in that file's lib/ directory, then in each colon-separated entry of the J_PATH environment variable. That's the whole module system — a convention, not a package manager: a "package" is just a directory of .j files on the search path. A typical project keeps its own modules under lib/ and imports them by name.
