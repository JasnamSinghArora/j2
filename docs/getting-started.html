Getting Started

Install J2, run a program, and meet the tools you'll use day to day.

Install

J2 ships as a single self-contained bundle for macOS (Apple Silicon), signed and notarized by Apple. Download the latest release archive from GitHub Releases, unpack it, and run the installer:

$ tar xzf j-<version>-aarch64-apple-darwin.tar.gz
$ cd j-<version>-aarch64-apple-darwin
$ ./install.sh

This installs J2 under ~/.j2 and links the j command onto your PATH. You can change the locations with environment variables:

$ J_PREFIX=/opt/j J_BINDIR=/usr/local/bin ./install.sh

The bundle includes everything J2 needs to compile programs — there is no separate Rust or package-manager install, and no network access is required.

If j isn't found after installing, add the bin directory to your shell profile, e.g. export PATH="$HOME/.j2/bin:$PATH" in ~/.zshrc.

Run a program

Put this in hello.j2:

print("Hello, world")

and run it:

$ j hello.j2
Hello, world

j file.j2 runs your program through the interpreter — it starts instantly and touches no compiler. That's the right mode for scripts and while you're writing code.

Build for speed

For compute-heavy work, compile to a native binary. The compiler also parallelizes idiomatic loops across your CPU cores automatically (see Auto-Parallelism):

$ j2 build kmeans.j2 -o kmeans
$ ./kmeans

You can also force the native path for a single run without producing a binary by setting J_FORCE_NATIVE=1 (see the CLI Reference).

The REPL

Start an interactive session with j2 repl to try expressions:

$ j2 repl
> x = 6 * 7
> print(x)
42

Editor support

A Visual Studio Code extension provides syntax highlighting, a Run command, and inline error reporting for .j2 files. Install it from the editors/vscode folder (open it in VS Code and press F5, or package it with vsce), then open any .j2 file and press Cmd/Ctrl+Shift+R to run.

A first program

A slightly larger example — a function, a loop, and a conditional:

# fizzbuzz up to n
func fizzbuzz(n) = {
    for i in 1..n {
        if i % 15 == 0 { print("fizzbuzz") }
        else if i % 3 == 0 { print("fizz") }
        else if i % 5 == 0 { print("buzz") }
        else { print(i) }
    }
}

fizzbuzz(20)

Note that 1..n is an inclusive range — it includes both 1 and n. Continue to the Language Guide for the full language.
