CLI Reference

The j command runs, builds, formats, and inspects J programs.

Commands

CommandDescription
j FILE.j [args...]Run a program. Uses the interpreter when possible (instant); falls back to a native compile for anything the interpreter doesn't handle. This is the default mode.
j run FILE.jExplicitly run through the interpreter.
j build FILE.j -o OUTCompile to a native binary at OUT, with auto-parallelism. Use this for speed-critical programs.
j emit-rust FILE.jPrint the lowered Rust source. Useful for checking that a program parses and lowers, and for understanding what the compiler produces.
j fmt FILE.jReformat a source file in place.
j replStart an interactive session.
j test [dir]Run every *.j file under dir (default j-tests) and report a pass/fail summary.

How a program runs

By default, j FILE.j tries the interpreter first — it starts instantly and uses no compiler. If a program uses a feature the interpreter doesn't support, J compiles it natively instead (and the Rust toolchain underneath stays hidden — you only ever see your program's output). For compute-heavy programs, prefer j build to get a native, parallelized binary you can run repeatedly.

Capabilities

Access to the filesystem, processes, and the network is denied by default. Grant it per run with a flag:

FlagGrants
--allow-fsthe fs module (read/write files)
--allow-procthe proc module (run processes, read env)
--allow-netthe http module (network requests)
--allow-allall of the above
--allow-unsafepermit low-level escape hatches in trusted code
$ j --allow-fs report.j        # may read/write files
$ j --allow-all pipeline.j     # full access

Environment variables

VariableEffect
J_FORCE_NATIVE=1Skip the interpreter and compile natively (same engine as j build).
J_NO_NATIVE=1Use the dynamic path instead of native lowering. Mainly for testing.
J_PARALLEL=0Compile natively but without auto-parallelism (single-threaded).
J_NO_NESTED=1Disable the nested-loop parallel matchers (matvec / conv1d). A safety kill-switch.
J_DEBUG=1On a native build failure, show the raw compiler diagnostics (normally hidden behind a J-level message).

If a program fails to compile natively, J prints a short message and points you to J_DEBUG=1 (for details) or J_NO_NATIVE=1 / j run (to use the interpreter instead).
